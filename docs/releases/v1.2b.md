## What's new since v1.2a

- Fixed several compatibility issues affecting learned words, loaded creatures,
  text input, shift-click editing, status reports and runtime resets.
- Creatures can show an angry expression, a guard prevents a hang when many
  creatures occupy drawing planes, dropped creatures land on the floor below,
  and held objects sit in the hand's grip. These fixes and their settings are
  described in [Bugs in the original game](https://github.com/h4rm0n1c/LibreCreatures/blob/main/docs/original-bugs.md).
- Expanded tests comparing LibreCreatures with the original game.

## Downloads and installation

Choose a regular build for the original-style world view, or a **neorender**
build for zoom, true-colour and double-resolution art, smooth motion and world
speed controls. The neorender build needs the included `SDL3.dll` alongside
`Creatures.exe`. Choose x86 (the reference build) or x64; on Wine, use x86 if
you want the kits to work. Each build needs the matching Microsoft Visual C++
2015–2022 runtime with MFC.

1. Install a legally obtained copy of Creatures 1 and LisDude's
   [Creatures 1 Community Edition](https://lisdude.com/Creatures/Community/C1/).
   LibreCreatures needs its `Launcher.exe`, which is not included in these
   downloads. On macOS or Linux, follow the Community Edition instructions and
   use its Wine Helper as directed.
2. Back up your worlds and the files you will replace. Copy the chosen zip's
   contents into the Creatures 1 installation folder, replacing files after
   installing Community Edition. The original game data is not included.
3. Start `Launcher.exe`, select or create a world, and start the game. The
   launcher manages world paths and kit registration.

**Wine users:** If the Community Edition launcher reports “Failed to get
Documents path.”, create the Documents folder used by your Wine prefix or
wrapper and try again. This is a limitation of the Community Edition launcher;
a LibreCreatures launcher is planned. Thanks to [@anon569](https://github.com/anon569)
for reporting and confirming the issue.

Options > LibreFixes lets you choose which switchable original-game fixes are
active. `SOURCE-CODE.txt` in each zip identifies its source commit. See the
[README](https://github.com/h4rm0n1c/LibreCreatures#downloads) for more details.
