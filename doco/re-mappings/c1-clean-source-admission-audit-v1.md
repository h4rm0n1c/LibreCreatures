## Admission rules

A clean implementation is admitted only by binary address, destination
file, and a normal source symbol. The queue destination must agree with
the admission record. Runtime/SDK implementations, absorbed helpers,
and placeholder bodies cannot be admitted as standalone source.
Framework metadata and absorbed/toolchain rows remain in the manifest
as resolved routing decisions; they are not counted as pending source
translations.

The address and evidence-side name live in this metadata report; they
are not inserted into C++ comments or identifiers.
